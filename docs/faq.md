# FAQ

## Is AlgoVista free?

Yes. MIT-licensed open source by VoxHash Technologies.

## Do I need an API key?

No. Optional analytics / Search Console codes only.

## Why was the repo renamed from `algovista-next`?

The product brand is **AlgoVista**. The `-next` suffix was a stale framework label; the package name was already `algovista`.

## Does it support offline / PWA install?

A web manifest and icons are provided. Full offline caching is not a current goal (see [ROADMAP.md](../ROADMAP.md)).

## Which Node version should I use?

Node 20 LTS is recommended; Node 18+ is supported.

## Where do I report security issues?

Privately to [contact@voxhash.dev](mailto:contact@voxhash.dev) — see [SECURITY.md](../SECURITY.md).
