# Support

## Getting help

1. Check [Troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md).
2. Search [existing issues](https://github.com/VoxHash/algovista/issues).
3. Open a new issue with the bug or docs template.
4. Email [contact@voxhash.dev](mailto:contact@voxhash.dev) for private or account-related questions.

## What to include

- AlgoVista version / commit SHA
- Node.js and npm versions (`node -v`, `npm -v`)
- OS
- Exact command that failed and full error output
- Whether the issue happens on the [live demo](https://algovista.voxhash.dev/) or only locally

## Response expectations

This is an open-source educational project maintained by VoxHash Technologies. Best-effort replies; no guaranteed SLA.
